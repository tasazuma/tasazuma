# 浅妻 利明 / Software Engineer

Webアプリケーション開発を中心に、フロントエンド・バックエンド・AWS環境構築から、要件整理・アーキテクチャ検討・プロトタイプ開発まで幅広く取り組んでいるソフトウェアエンジニアです。

「こんなものがあったら面白い・便利なのでは？」というアイデアを、要求・設計に落とし込み、実際に動くものにして検証していくことが好きです。

現在は **生成AIをソフトウェア開発やサービス企画の中でどのように活用できるか** にも関心を持ち、ChatGPTなどを利用した要求整理、設計、調査、開発支援などを実践しながら、AIとエンジニアが協働する開発スタイルを模索しています。

個人プロジェクトとして **ex-day** を企画・開発しています。

## 🤖 AI × Software Engineering

生成AIそのものを開発するだけでなく、**既存のソフトウェア開発やサービス開発にAIをどう組み込み、エンジニアの能力を拡張できるか**に関心があります。

現在はChatGPTなどの生成AIを活用しながら、次のような取り組みを試しています。

- アイデア・サービス企画の壁打ち
- 要求・要件の整理
- アーキテクチャ・技術選定の検討
- 実装・コードレビュー支援
- 技術調査・比較
- ドキュメント作成
- AIを利用した開発ワークフローの検討

AIにすべてを任せるのではなく、エンジニア自身が技術を理解した上で、**AIとどのように役割分担すると開発の質と速度を高められるのか**を実践を通して探っています。

## 🚀 ex-day

**いつもの一日に、ちょっとした発見を。**

位置・時間・興味をもとに、歴史、地域の出来事、イベント、旬のものなど、「ちょっと寄り道してみよう」と思える情報との出会いを作るプロジェクトです。

まだ構想・プロトタイプ段階ですが、開発だけでなく、アイデアや地域情報の提供、企画など、さまざまな形で一緒に作ってくれる仲間を探しています。
